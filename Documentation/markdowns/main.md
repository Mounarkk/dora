# 3D scene exploration through head and gaze positions

## Abstract  
This project explores how an observer’s head and gaze positions can be used to interact with a 3D environment, simulating a window-like experience where moving one's head alters the point of view on the scene. Gaze data may also drive dynamic modifications to the environment.

## Project principle  
We aim to create a noninvasive immersive setup that allows users to explore a 3D scene naturally through:

1. **Head position tracking** to dynamically update the camera position, simulating a physical window into a 3D world.
2. **Gaze tracking** to gather perceptual data or drive scene changes (e.g., light, material, geometry), supporting experiments on visual attention and change blindness.

This interaction opens possibilities to manipulate the visual experience subtly, leveraging effects like motion parallax or gaze-contingent distortions.
